# Nimbus — prototype d'apprentissage Tailwind CSS

Nimbus est une maquette de tableau de bord statique créée pour pratiquer la composition responsive avec les utilitaires Tailwind CSS. Les filtres, la recherche et le menu mobile fonctionnent dans le navigateur; les données affichées sont entièrement fictives et aucun backend n'est connecté.

Le projet utilise le Play CDN Tailwind pour essayer les classes sans étape de build. La documentation Tailwind réserve ce CDN à l'expérimentation; une version de production devra compiler le CSS.
